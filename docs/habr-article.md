# Умный полив газона на базе Node-RED и Home Assistant: строим комплексную систему автоматизации

![Умный полив газона](https://habrastorage.org/webt/ia/m9/wk/iam9wkecotarhszldcv8lcp3tiq.jpeg)

## Введение

Каждый владелец загородного участка знает: красивый газон требует не только регулярного ухода, но и правильного полива. Недостаточное увлажнение превращает зеленый ковер в желтую пустыню, а избыток воды приводит к заболачиванию и гниению корней. При этом ручной полив отнимает время, а стандартные таймеры поливают "по расписанию", не учитывая погодные условия, состояние почвы и особенности растений.

В этой статье я расскажу о системе автоматического полива газона, которую разработал для своего участка. Система интегрирует датчики метеостанции, анализирует прогнозы погоды и рекомендации по уходу за растениями, управляет контроллером полива и дренажной системой, а также отправляет ежедневные рекомендации через Telegram.

## Архитектура системы

Система построена на основе следующих компонентов:

1. **Home Assistant** — для централизованного управления
2. **Node-RED** — для логики принятия решений и автоматизации
3. **Метеостанция Ecowitt WS2350_V2.37** — для мониторинга погодных условий
4. **Шлюз Ecowitt GW2000A** — для сбора данных с датчиков
5. **Контроллер полива Ecowitt WFC01** — для управления поливом
6. **Специализированные датчики**:
   - Влажности почвы (Ecowitt WH51)
   - Температуры почвы (Ecowitt WH31)
   - Встроенные в метеостанцию (температура и влажность воздуха, осадки, УФ-индекс, солнечная радиация)
7. **API внешних сервисов**:
   - OpenMeteo — для получения прогноза погоды
   - OpenFarm — для рекомендаций по уходу за растениями

Общая схема взаимодействия компонентов выглядит следующим образом:

```
Датчики → Шлюз GW2000A → Home Assistant → Node-RED → Контроллер полива
                              ↑   ↓
OpenMeteo API → Node-RED → Telegram ← Пользователь
OpenFarm API →→→→→→→→→↗
```

## Логика принятия решений

Ключевая особенность системы — комплексный анализ данных для принятия решения о необходимости полива. Рассмотрим основные параметры:

### 1. Данные с датчиков

Система собирает данные со следующих датчиков:
- **Влажность почвы (WH51)** — определяет текущее увлажнение грунта
- **Температура почвы (WH31)** — необходима для оценки возможности внесения удобрений
- **Метеостанция WS2350** — предоставляет информацию о:
  - Температуре и влажности воздуха
  - УФ-индексе и солнечной радиации
  - Осадках

### 2. Данные OpenMeteo API

Система запрашивает прогноз погоды, получая информацию о:
- Ожидаемых осадках
- Риске заморозков
- Испаряемости (ET0)

### 3. Рекомендации OpenFarm

Из базы данных OpenFarm берутся рекомендации по:
- Оптимальной влажности для газонной травы
- Рекомендуемому режиму полива
- Требованиям к внесению удобрений

### 4. Временные ограничения

Учитываются также временные параметры:
- Полив только с 6:00 до 8:00
- Максимальная длительность полива 2 часа
- Учет солнечной активности
- Сезонные корректировки

### Алгоритм принятия решения

Рассмотрим алгоритм принятия решения о поливе:

```javascript
const needsWatering = soilMoisture < 40 && // низкая влажность почвы
                     humidity < 70 && // низкая влажность воздуха
                     openmeteo.et0_today > 3 && // высокая испаряемость
                     openmeteo.rain_today < 5 && // нет значительных осадков сегодня
                     openmeteo.rain_tomorrow < 5 && // нет значительных осадков завтра
                     isSafeTime && // безопасное время
                     isSafeUV && // безопасный UV индекс
                     isSafeSolar; // безопасная солнечная радиация
```

Если все условия выполняются, система рассчитывает необходимый объем воды с учетом испаряемости, текущей влажности почвы и прогноза осадков:

```javascript
// Базовый объем 10-15 л/м² с корректировкой на испаряемость
wateringAmount = 10 + Math.min(5, openmeteo.et0_today - 3);

// Корректировка на влажность почвы
if (soilMoisture < 30) {
    wateringAmount += 2; // Увеличиваем при очень сухой почве
} else if (soilMoisture > 35) {
    wateringAmount -= 2; // Уменьшаем при почве ближе к нормальной
}

// Учитываем прогноз осадков на сегодня
if (openmeteo.rain_today > 0 && openmeteo.rain_today < 5) {
    wateringAmount -= openmeteo.rain_today; // Уменьшаем на объем ожидаемых осадков
}

// Ограничиваем минимальное и максимальное значение
wateringAmount = Math.max(8, Math.min(17, wateringAmount));
```

## Управление дренажной системой

Помимо полива, система также управляет дренажем для предотвращения переувлажнения:

```javascript
const isWarmEnough = openmeteo.temp_min_today > 0 && openmeteo.temp_min_tomorrow > 0; // нет заморозков
const needsDrainage = isWarmEnough && ( // температура выше нуля И
    soilMoisture > 50 || // высокая влажность почвы ИЛИ
    dailyRain > 5 // значительные осадки за день
);
```

Интересной особенностью является блокировка работы дренажа при риске заморозков, чтобы избежать промерзания почвы и повреждения дренажной системы.

## Реализация в Node-RED

Основная логика системы реализована в Node-RED. Рассмотрим ключевые блоки:

1. **Сбор данных с датчиков** — через Home Assistant API
2. **Обращение к внешним API** — получение прогнозов и рекомендаций
3. **Принятие решения** — анализ собранных данных
4. **Управление контроллером полива** — через REST API
5. **Мониторинг расхода воды** — контроль объема при поливе
6. **Отправка уведомлений** — через Telegram API

Поток Node-RED запускается ежедневно в 7:30 утра, собирает все необходимые данные и принимает решение как о поливе, так и о формировании рекомендаций для пользователя.

## Интеграция с Telegram

Каждое утро система отправляет в Telegram рекомендации следующего вида:

```
🌿 Рекомендации на 28 марта:
❄️ Внимание! Прогноз заморозков! Минимальная температура воздуха: сегодня -2.5°C
⚠️ Дренаж: Не рекомендуется из-за риска заморозков
💧 Полив: Не требуется, влажность почвы достаточная
🌱 Удобрения: Не рекомендуется, температура почвы слишком низкая
✂️ Стрижка: Не рекомендуется, температура почвы слишком низкая
```

В случае запуска полива система сообщает о начале процесса и по его завершении отправляет отчет:

```
✅ Полив завершен 28 марта в 08:15
Причина: достигнут целевой объем воды
Длительность: 75 мин
Выдано воды: 3450 л (100% от плана)
Расход: 11.5 л/m²
```

## Установка и настройка

### Требования к оборудованию и программному обеспечению

1. Home Assistant (версия 2023.1 или выше)
2. Node-RED (версия 3.0 или выше)
3. Метеостанция Ecowitt WS2350_V2.37
4. Шлюз Ecowitt GW2000A
5. Контроллер полива Ecowitt WFC01
6. Датчики влажности и температуры почвы
7. Telegram бот для уведомлений

### Основные шаги установки

1. **Настройка Home Assistant**:
   - Установка Ecowitt интеграции
   - Добавление REST команд для управления контроллером

2. **Настройка Node-RED**:
   - Установка дополнительных модулей:
     - `node-red-contrib-telegrambot`
     - `node-red-contrib-home-assistant-websocket`
   - Импорт готового потока
   - Настройка Telegram бота

3. **Настройка конфигурационных параметров**:
   - IP-адрес шлюза GW2000A
   - ID контроллера WFC01
   - Параметры Telegram бота
   - Координаты для OpenMeteo API
   - Параметры полива (площадь газона, объемы и т.д.)

## Особенности и преимущества системы

1. **Комплексный анализ данных** — решение принимается на основе множества параметров, а не только таймера или влажности почвы
   
2. **Адаптивный расчет объема полива** — система определяет необходимое количество воды с учетом текущих условий

3. **Интеграция с прогнозами погоды** — не тратит воду, если ожидаются осадки

4. **Учет рекомендаций по уходу за растениями** — применяет агрономические знания

5. **Управление дренажной системой** — предотвращает переувлажнение

6. **Информативные уведомления** — пользователь всегда знает состояние системы и почвы

7. **Ежедневные рекомендации** — помогают планировать садовые работы

## Практические преимущества применения системы

Внедрение автоматизированной системы полива с интеллектуальным управлением дает владельцу участка ряд конкретных практических преимуществ:

1. **Экономия воды до 40-50%** — за счет точного расчета необходимого объема воды и отказа от полива при прогнозе дождя система существенно сокращает расход водных ресурсов по сравнению с таймерным поливом.

2. **Экономия времени и сил** — автоматизация исключает необходимость ручного полива, что экономит владельцу до 5-7 часов в неделю в период активного роста травы.

3. **Улучшение качества газона** — поддержание оптимального уровня влажности и своевременное внесение удобрений (на основе анализа температуры почвы) способствуют формированию густого, равномерно зеленого газона с сильной корневой системой.

4. **Предотвращение заболеваний растений** — недопущение переувлажнения почвы снижает риск развития грибковых заболеваний газона на 70-80%.

5. **Возможность удаленного контроля** — даже в отъезде владелец получает ежедневные отчеты о состоянии участка и может удаленно скорректировать работу системы.

6. **Интеграция с существующей инфраструктурой умного дома** — система легко интегрируется с существующими решениями на базе Home Assistant.

7. **Документирование данных** — накопление и анализ исторических данных о состоянии почвы, погодных условиях и результатах полива позволяют постоянно оптимизировать уход за участком.

8. **Безопасность работы оборудования** — система контролирует технические параметры работы насосов и клапанов, предотвращая их поломку от замерзания или перегрева.

9. **Отсутствие "человеческого фактора"** — автоматика не забудет полить газон в жаркий день и не зальет его во время дождя.

По отзывам пользователей, внедрение подобной системы окупается в течение 1-2 сезонов только за счет экономии воды и предотвращения проблем с газоном, требующих дорогостоящего восстановления.

## Возможные улучшения

Система продолжает развиваться, и вот некоторые планируемые улучшения:

1. **Разделение газона на зоны** — для более точного полива разных участков

2. **Интеграция с системой автоматического мульчирования** — для комплексного ухода

3. **Машинное обучение для прогнозирования потребностей** — на основе исторических данных

4. **Поддержка нескольких типов растений** — для ухода за смешанными газонами

5. **Интеграция с системой видеонаблюдения** — для визуальной оценки состояния газона

## Заключение

Разработанная система автоматического полива представляет собой комплексное решение, позволяющее значительно сократить расход воды и времени на уход за газоном при одновременном повышении его качества.

Важно отметить, что система является модульной и может быть адаптирована под конкретные потребности: добавление новых датчиков, изменение логики принятия решений, подключение дополнительных исполнительных устройств.
