# Инструкция по установке системы автоматического полива

## Предварительные требования

1. Установленный Node-RED
2. Установленный Home Assistant
3. Контроллер полива Ecowitt WFC01
4. Датчики:
   - Влажности почвы
   - Температуры почвы
   - Осадков
   - UV индекса
   - Солнечной радиации

## Шаг 1: Настройка Node-RED

1. Откройте Node-RED в браузере
2. Перейдите в меню (три точки в правом верхнем углу)
3. Выберите "Import"
4. Загрузите файл `node-red/flows/agro.json`
5. Нажмите "Import"

## Шаг 2: Настройка Home Assistant

1. Откройте файл конфигурации Home Assistant (`configuration.yaml`)
2. Добавьте содержимое файла `home-assistant/configuration/wfc01.yaml`
3. Перезапустите Home Assistant

## Шаг 3: Настройка интерфейса

1. Откройте Lovelace в Home Assistant
2. Добавьте новую карточку
3. Вставьте содержимое файла `home-assistant/lovelace/button.yaml`
4. Сохраните изменения

## Шаг 4: Настройка конфигурации

1. Скопируйте файл `config.example.yaml` в `config.yaml`
2. Отредактируйте `config.yaml`:
   - Укажите IP-адрес контроллера WFC01
   - Настройте параметры полива
   - Укажите пороговые значения датчиков

## Проверка работоспособности

1. В Home Assistant должна появиться карточка управления поливом
2. В Node-RED должны быть активны все ноды
3. Проверьте получение данных от датчиков
4. Протестируйте ручное включение полива

## Устранение неполадок

1. Проверьте логи Node-RED на наличие ошибок
2. Убедитесь, что все датчики доступны
3. Проверьте подключение к контроллеру WFC01
4. Проверьте корректность настроек в `config.yaml`
