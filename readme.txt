Что бы управлять вентилем Ecowitt WFC01 нам нужно обратиться к нему через REST. Определите IP адрес вашего HUB (в моем случае это GA2000).
Для запроса всех подустройств (iot-устройств) также есть конечная точка:
http://192.168.xx/get_iot_device_list (device-id не равен 123, я изменил его на это)
Ответ: {"command":[{"cmd":"read_quick","model":1,"id":123,"ver":113,"rfnet_state":1,"battery":5,"signal":4}]}

Хорошо, опишу структуру и логику работы системы полива:

1. **Триггер запуска**
- Ежедневный запуск в 7:30 утра
- Инициирует параллельный сбор данных со всех датчиков и источников

2. **Сбор данных (8 источников)**:
- **Датчики окружающей среды**:
  * Влажность почвы (soil_moisture)
  * Температура почвы (soil_temp)
  * Осадки за день (daily_rain)
  * Влажность воздуха (humidity)
  * UV индекс (uv)
  * Солнечная радиация (solar)

- **Внешние API**:
  * OpenMeteo (прогноз погоды)
  * OpenFarm (рекомендации по уходу)

3. **Обработка данных**:
- Нода Join собирает данные со всех 8 источников
- После сбора данные передаются в два параллельных потока:
  * Генерация советов
  * Принятие решения о поливе

4. **Генерация советов**:
- Анализирует все параметры и формирует рекомендации:
  * Предупреждения о заморозках
  * Необходимость полива
  * Рекомендации по удобрениям
  * Советы по дренажу
  * Рекомендации по стрижке
- Отправляет сформированные советы в Telegram

5. **Принятие решения о поливе**:
- **Проверка условий безопасности**:
  * Время (6:00-8:00)
  * UV индекс (<2)
  * Солнечная радиация (<100 Вт/м²)

- **Проверка необходимости полива**:
  * Влажность почвы (<40%)
  * Влажность воздуха (<70%)
  * Испаряемость (ET0 >3)
  * Прогноз осадков (<5мм)

6. **Управление поливом**:
- **Если полив требуется**:
  * Расчет объема воды (8-17 л/м²)
  * Запуск полива
  * Мониторинг расхода воды
  * Контроль времени (макс. 2 часа)
  * Остановка при достижении цели
  * Логирование результатов

- **Если полив не требуется**:
  * Логирование причин отказа
  * Отправка уведомления

7. **Система безопасности**:
- Ограничение времени работы
- Контроль условий окружающей среды
- Мониторинг объема воды
- Защита от ошибок

8. **Логирование**:
- Запись всех событий
- Причины начала/отказа от полива
- Статистика расхода воды
- Отправка отчетов в Telegram

9. **Обработка ошибок**:
- Catch-нода для перехвата ошибок
- Логирование проблем
- Безопасное завершение работы

Система спроектирована с учетом безопасности и эффективности полива, использует множество параметров для принятия решений и имеет подробное логирование всех действий.
